# CRM operations release

This release adds Visits, Calls & activity, Activity reports, an admin audit trail, reviewed duplicate merges, active usage tracking and encrypted backups.

- Employee access is restricted to assigned visits, owned leads and their own activity/usage. Administrators can see the team and use the audit/merge/backup screens.
- Database audit events are generated by a private trigger and cannot be inserted, changed or deleted through the normal app API.
- Merging is a reviewed administrator action for the same shareholder and company. It preserves the source row, original snapshots and notes. Undo is blocked when records have since changed.
- Active usage is recorded only while the CRM is visible and there was interaction within five minutes. Server timestamps cap increments and multiple tabs do not double-count. Usage is not certified attendance.
- Reports distinguish employee-entered call/email logs from visit completions and current pipeline counts. No historical activity or active hours were fabricated.
- All displayed visit times are IST.
- The first encrypted backup contains 1,447 leads, four members and four profiles. A decrypt round-trip and isolated restore check passed.
- Daily encrypted Google Drive backups are scheduled for 02:00 Asia/Kolkata through the connected computer. Its runtime, protected key and connected Supabase/Drive access must remain available.
- Protected recovery keys and raw backups are never committed. User recovery deliverable is stored locally, separately from Drive backup files.
- Authentication accounts and deployment code are managed separately from CRM data backups. Historical session identifiers are excluded; restoring session history requires new inert session IDs and closing those historical rows at their last-seen time.
