Refine the ENTIRE Claim 360 CRM interface into a coherent, polished enterprise
product. Follow DESIGN.md. Generate a high-fidelity desktop product design board
showing a realistic shareholder directory with its navigation shell, plus shared
form controls and status treatments in a companion panel. This is a design system
reference for implementing all the app screens, not a landing page.

Typography is the main priority: Inter Variable for readable body text and Manrope
Variable for headings. Body and table cells 14px, form labels 13px, buttons 13px,
navigation 13px, supporting text at least 12px and short eyebrows at least 10px.
Use a 32px main title, 20px section headings, comfortable 1.5 line height, clear
contrast, and restrained font weights. Avoid tiny all-caps text and dense controls.

Use a 256px navy sidebar with grouped navigation: Workspace (Overview, All leads,
Follow-ups), Operations (Visits, Calls & activity), Management (Reports, Import
CSV, Team). Include a quiet profile menu, a simple white top bar, teal active
states, warm pale-gray canvas, white cards, 14px corners and subtle borders.

The main directory has a clear title and new-lead action, a well-spaced toolbar
with search, status and location filters, a readable table with checkbox,
shareholder identity, company, owner, status, follow-up and record action, and
clear pagination. Show an honest empty state with an Add shareholder action.
In a companion area show labeled text fields, selects, textarea, normal/focus/
disabled states, primary/secondary/danger buttons and a restrained status palette.

No fictional customers, financial amounts, performance claims, certifications,
paid offerings, or fake counts. Do not add controls without existing CRM behavior.
This design must translate naturally to employee, team, visits, reports, imports,
profile, email composer and lead-editor screens, including dark and mobile modes.
